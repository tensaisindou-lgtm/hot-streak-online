# 🔥 HOT STREAK Online v1

v7のレース部分を残し、Socket.IOで「ルーム作成→URL共有→2〜4人待機→秘密手札→同期ドロー」の土台を追加した版です。

## 起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## 友達と遊ぶ

この段階は「同じサーバーへ接続できる環境」が必要です。公開URLにする場合は、このNode.jsプロジェクトをNode対応ホスティングへデプロイします。

## 現在できること

- 2〜4人ルーム
- ルームコードをURLクエリに保持
- ホストが人数を決定
- 全員READYでゲーム開始
- 公開14枚をサーバー側で生成
- 各プレイヤーの3枚手札を本人だけへ送信
- 1枚選択、残り2枚を除外
- 誰が何を選んだかは他プレイヤーへ送信しない
- 最終デッキをサーバー側で管理
- カードドローをサーバー側でロックして全員へ同期
